# Шаблон ручного прогону

Створюйте окремий каталог для кожного пункту `Mxx`, наприклад `M01-frame-reader/`, і зберігайте журнал у Git. Невдалий прогін лишається в історії після виправлення.

Скопіюйте цей шаблон до журналу прогону й заповніть усі поля:

```text
Пункт Mxx і сценарій:
Дата й час з часовим поясом:
Git commit, машина й версії інструментів:
Робочий каталог і точна команда:
Вхідні файли, конфігурація та seed (якщо є):
Очікуваний результат до запуску:
Фактичний результат і код завершення:
stdout/stderr або шлях до компактного експорту:
Висновок і наступна дія / commit виправлення:
```
