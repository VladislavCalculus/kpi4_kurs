Тести байтового джерела та фреймінгу MAVLink запускаються командою `ctest --test-dir build --output-on-failure`. `frame_reader` перевіряє повні MAVLink 1/2 кадри, поганий CRC і обрізаний кадр із бінарних фікстур; `cli_bad_crc` і `cli_truncated` перевіряють підсумкові лічильники CLI. Перевірки змісту місії, контрактів і геометрії додаються разом із відповідною поведінкою.
