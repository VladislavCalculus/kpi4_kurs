Тести байтового джерела та фреймінгу MAVLink запускаються командою `ctest --test-dir build --output-on-failure`. `frame_reader` перевіряє повні MAVLink 1/2 кадри, поганий CRC і обрізаний кадр із бінарних фікстур; `frame_reader_chunks` порівнює видані кадри й лічильники для всіх позицій поділу кадру, збережених трьох порцій, різних розмірів буфера та кількох кадрів в одній порції. `frame_reader_recovery` і `cli_recovery` перевіряють відновлення після шуму, кадру без останнього байта CRC, поганого CRC та некоректного заголовка. `frame_log` перевіряє UTC-час, числові поля та прапорець підпису із фіксованим часом; `cli_metadata_v1/v2` перевіряють вивід з реальних фікстур. Перевірки змісту місії, контрактів і геометрії додаються разом із відповідною поведінкою.
