# KPI4 — модуль корекції траєкторії БПЛА

Курсовий проєкт присвячений бортовому модулю, який веде автономний БПЛА за маршрутом і коригує відхилення. Ground Station перед польотом завантажує місію через MAVLink. Під час польоту модуль отримує актуальний стан із бортового джерела, зокрема GPS, обчислює нову ціль руху й передає її контролеру X. Контролер відповідає за стабілізацію та мотори. Постійне з'єднання з Ground Station для контуру корекції не потрібне.

ПК-читалка MAVLink уже перевіряє кадри, CRC та незалежні логічні канали. Протокольна бібліотека декодує `HEARTBEAT` і повідомлення місійного обміну, нормалізує глобальні цілі у WGS84 з явним altitude reference та наразі приймає в місії лише `MAV_CMD_NAV_WAYPOINT`; [ручний прогін M01](devlogs/manual/M01-frame-reader/README.md) зберігає команди й результати фреймінгу. Математика корекції, конкретна MAVLink-команда для контролера, джерело бортового стану й апаратна платформа ще не вибрані.

Вимоги до інструментів ПК-розробки: [docs/build.md](docs/build.md).

Декодери `GLOBAL_POSITION_INT` і `GPS_RAW_INT` передають оцінений стан та сирі GNSS-дані до спільного `StateProvider`/`StateSample`. Симулятор використовує такий самий інтерфейс. Інтеграція явно задає монотонні моменти вимірювання й прийому; перевірка свіжості та придатності стану ще не реалізована. Тест `state_provider` порівнює еквівалентні дані з MAVLink і симулятора.
